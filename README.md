# Howl's Moving Café ☕

A web-based café management system built with **PHP, MySQL, HTML, and CSS**.  
Users can browse menus, add items to cart, place orders, leave a message/query and admins can manage products, queries and orders.



## 🚀 Features
- User signup/login  
- Browse menu and add items to cart  
- Checkout and order history  
- Admin panel for managing items, orders, and inquiries  
- Responsive design with custom CSS
